# 技能存储采用去中心化方案（GitHub 仓库）

技能数据存储在 GitHub 仓库中，而非中心数据库。Web 端通过 GitHub API 读取技能数据，构建时缓存。

**Considered Options:**

- **A. 中心数据库**（类似 doraemon）— 技能文件存入 MySQL，API 提供服务。完全控制但需承担存储和同步成本。
- **B. 去中心化**（GitHub 仓库）— 技能存在 GitHub，Web 端索引展示。零存储成本，数据始终最新。
- **C. 混合模式** — GitHub 索引 + 数据库缓存。两全其美但复杂度高。

选择 B 的理由：当前阶段只有一个仓库、少量技能，去中心化最简单。GitHub 天然提供版本控制、PR 审核、文件托管，无需额外基础设施。
